# 完成并汇报本次执行

逐项核对交付、既定设计、调用方契约、边界及可能的回归。对改动运行最小相关检查和任务或项目要求的验证。产物适用启动检查时，使用正常入口实际启动并核对行为。记录命令与观察结果。对不适用或尚未验证的项写明原因。

写入前重读最新文件，保留其它任务的修改。可协调的局部修改自行合并。涉及同一符号或共享契约的竞争时，向主任务报告依赖。检查自己的 diff，逐项记录必要的跨范围修改及原因。

遇到失败时，尝试授权范围内的等价办法并验证。结束前在指定的 attempt 报告写明实际操作、文件、验证覆盖范围、命令、结果、未测项、后续修改对证据的影响及待主审核对的事项。复用仍有效的检查。
