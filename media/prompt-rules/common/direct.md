# 判断当前事项能否直办

首次、补充、继续和收尾回合都按同一条件判断。目标明确、操作局部且低风险、结果可直接确认，无需独立调查、设计或协作，并且用户和项目均未要求测试、构建或独立验收时，主任务可以直接完成该事项。范围、权限、安全、重要数据、共享契约、回归风险和验证需要决定能否直办。文件数、行数、标题和扩展名不足以做此判断。

独立小事直办后，仍有其它工作时按当前状态派发、等待或验收。只有原始与补充目标全部满足、规定的验证已完成且宿主允许收尾时才能返回 completed。保持运行、排队及待验收工作的写入归属。复杂任务仍按整体风险委派与验收，子模型配置失败时由宿主处理，主任务不能替执行者修复产物。
