# Sinitek AI VS Code CLI 插件

Sinitek AI VS Code CLI 插件（携宁 CLI 助手）为 VS Code 提供一个统一的 AI 工作台。无需离开编辑器，即可使用本机的 Codex、Claude 或 OpenCode CLI 进行对话、编程和复杂任务协作。

## 核心特性

### 统一使用多个 AI CLI

- 在 VS Code 内切换 Codex、Claude 和 OpenCode。
- 为不同 CLI 设置独立的命令、参数、配置档案、模型和思考模式。
- 统一展示流式回复、思考状态、工具调用、执行日志和最终结果。
- 支持多标签会话、并行任务、历史会话恢复和会话关键词搜索。

### 丰富的上下文与交互

- 在提示词中添加文件、当前编辑器内容和选中代码等上下文。
- 支持附件、提示词历史、收藏提示词和当前会话搜索。
- AI 需要补充信息时，通过表单向用户提问并继续任务。
- 实时展示任务列表、子任务进度、工具 trace 和上下文使用情况。

### 多种任务模式

- **Vibe（coding）**：适合日常问答、代码编写、修改和调试。
- **Loop**：将复杂目标拆分为多个子任务，支持多轮推进、协作沟通和人工确认。
- **Loop+**：在 Loop 基础上提供更完整的子任务派发、验收和协作控制。
- **Graph**：由 AI planner 生成可视化 DAG，查看节点状态、依赖关系和执行进度，并支持继续、重试、停止和失败返工等恢复操作。

### 配置中心

- 可视化管理 Codex、Claude 和 OpenCode 的配置档案。
- 配置模型、Provider、思考强度、规则、工作区设置和任务执行选项。
- 支持执行后自动压缩上下文、历史记录保留和人工交互开关。
- 提供配置备份、导出、日志查看和 CLI 找不到时的诊断与修复入口。

### Skills 与 MCP

- 浏览和管理官方 Skills，为 AI 添加项目开发、分析和自动化能力。
- 通过 MCP 市场安装、卸载和检测 MCP 服务。
- 支持本地 MCP 与远程 MCP，并保留已有 CLI 配置和其他服务。

### 本地记忆与可靠运行

- 可选启用插件侧长期记忆，帮助 AI 延续项目上下文和历史经验。
- 会话、任务和配置状态在本地持久化，重新打开 VS Code 后可以继续使用。
- 支持中英文界面、调试日志、历史清理和异常提示。

## 开始使用

1. 先在本机安装并完成鉴权或配置至少一个 CLI：Codex、Claude 或 OpenCode。
2. 首次加载时，**Sinitek CLI Assistant** 默认在辅助栏打开（通常在右侧），也可通过状态栏或命令面板打开。
3. 选择要使用的 CLI，输入提示词即可开始对话或创建任务。

聊天面板使用 VS Code 1.104 引入的辅助栏入口；已保存的视图位置继续由 VS Code 恢复，不会在启动或 `run_dev.sh` 重载时强制移动到主侧栏。关闭 `sinitek-cli-tools.autoOpenPanel` 后也不会自动展开面板。

插件调用的是本机已安装的 CLI，不提供远程托管服务，也不替代各 CLI 自身的安装、鉴权和高级配置。当前版本不再支持 Gemini CLI。
