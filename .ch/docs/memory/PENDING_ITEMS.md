# 未完成事项

这个文件只保留**跨会话仍然开放**、且需要后续继续跟进的事项。

## 什么时候更新

- 一个任务本轮未做完，但明确还有下一步
- 已对用户作出承诺，但尚未完成
- 某项后续动作被记录进技术债或后续阶段

## 不该写什么

- 已完成事项
- 没有 owner 或来源的模糊想法
- 长期产品 backlog 的全部明细

## 维护规则

- 每一项都应写清楚：状态、owner、来源、下一步。
- 完成后应尽快删除，或迁移到对应历史文档，不在这里堆积“已完成”记录。
- 如果事项已经升级成正式计划，应优先链接计划，而不是在这里重复写细节。
