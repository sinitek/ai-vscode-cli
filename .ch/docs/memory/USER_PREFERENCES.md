# 用户偏好

这个文件只记录**用户明确表达过**、且希望长期保持的协作或实现偏好。

## 什么时候更新

- 用户明确要求长期保持某种实现、沟通、验证或工具使用方式
- 旧偏好被用户明确废弃或替换

## 不该写什么

- 代理自己的猜测
- 单次任务里的临时妥协
- 只出现一次、没有重复价值的口头偏好

## 建议结构

### 编码偏好

- starter 默认留空；接入真实项目后补充已确认的实现风格、约束和禁忌。

### 验证偏好

- starter 默认留空；接入真实项目后补充测试、构建、交付验证方面的稳定要求。

### 沟通偏好

- starter 默认留空；接入真实项目后补充用户希望长期保持的沟通方式。

### 工具偏好

- starter 默认留空；接入真实项目后补充常用工具优先级、禁用项或审批边界。

### 事实来源

- 每条偏好都应能追溯到用户明确表达的位置，例如 `AGENTS.md`、规格、计划或已确认的交互结论。
