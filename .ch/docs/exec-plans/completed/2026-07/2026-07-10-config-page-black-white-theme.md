## 背景

携宁 CLI 配置页同时使用 VS Code 主题变量、Ant Design 默认令牌和局部硬编码样式，导致列表、卡片、表单、按钮及弹窗之间的背景和文字颜色不一致。Skills 安装弹窗已先行改为黑白风格，需要对整个配置页做同类审查和统一。

## 目标

将携宁 CLI 配置页统一为黑色主色、白色辅色的视觉体系，确保主要界面均为白底黑字，主操作和选中状态使用黑底白字，同时保持交互状态可读和样式作用域可控。

## 范围

- 配置页顶栏、左侧配置列表、右侧编辑区。
- 配置卡片、表单控件、按钮、标签、提示和空状态。
- 导入导出、MCP、Skills、范例等配置页弹窗。
- Ant Design 主题令牌与配置页自定义 CSS 变量。

## 非目标

- 不修改配置读写、CLI 调用、Skills 或 MCP 业务逻辑。
- 不重构打包产物结构或替换 Ant Design、Monaco 等技术栈。
- 不改变 Monaco 语法高亮规则；仅保证编辑器容器与页面黑白风格协调。

- [x] 配置页主要容器、卡片、输入控件和弹窗均为白底黑字。
- [x] 顶栏、主按钮、选中项和选中页签统一为黑底白字。

## 风险与缓解

- 风险：全局覆盖 Ant Design 样式可能影响禁用、悬停、危险操作等状态。
- 缓解：通过配置页根主题和配置页专属作用域覆盖，并为交互状态增加静态断言。
- 风险：直接替换编辑器主题可能降低代码可读性。
- 缓解：保留 Monaco 语法高亮，只统一外围容器、边框和背景关系。
