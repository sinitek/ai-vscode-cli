# 重置会话改为关闭旧会话并新建会话

- 日期：2026-06-11
- 状态：completed
- 负责人：Codex

## 背景

当前 AI 对话里的“重置当前会话”会在原有会话 Tab 上直接清空会话绑定与草稿消息，再继续在同一个 Tab 中发送后续请求。这样会让原 Tab 脱离旧会话历史，用户之后只能依赖历史列表恢复，且重置动作本身会破坏“当前 Tab 仍代表原会话”的语义。

## 目标

把“重置当前会话”改为关闭当前会话 Tab 并创建一个新的空白会话 Tab，保留旧会话记录与消息文件，避免把旧会话容器直接复用成新会话。

## 范围

- 调整 `src/extension.ts` 中 `resetConversationTabSession` 的处理逻辑
- 复用现有会话 Tab 和会话历史存储机制
- 同步最小必要文档

## 非目标

- 不改动会话消息文件格式
- 不重构会话历史 UI
- 不调整“删除会话”“清空所有历史”的语义

## 验收标准

- [x] 重置后进入新的空白会话，而不是在旧会话 Tab 上继续复用
- [x] 交互 Runner 不会因旧 Tab 关闭而错误保留或误删
- [x] `npm run build` 通过

## 风险与缓解

- 风险：关闭旧 Tab 时误触发最后一个 Tab 的兜底逻辑，导致没有真正切换到新会话
- 缓解：先创建新 Tab，再关闭旧 Tab，避免命中“最后一个 Tab 不关闭”的分支

- 风险：旧 Tab 关闭后误回收仍被引用的 interactive runner
- 缓解：复用现有 `closeConversationTabAndRefreshPanel` / `disposeInteractiveRunnerIfUnused` 机制，按 Tab 引用关系回收
