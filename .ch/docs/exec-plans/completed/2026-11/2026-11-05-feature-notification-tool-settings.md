# 通知授权迁移至工具设置

- 日期：2026-11-05
- 状态：completed
- 负责人：Codex
- 类型：feature

## 背景与目标

将“使用说明”的通知授权页签迁移到“工具设置”，保留 Mac 授权状态、手动授权、拒绝后的系统设置入口与其他平台说明。提供“任务完成通知”和“人机交互通知”两个独立、默认开启的系统通知开关，复用现有应用级 VS Code 配置，保留已有选择，不另建权限或配置来源。不改变窗口图标提醒、通知投递条件、系统权限和默认值，不发布、不提交。

## 范围与非目标

- 生产Webview HTML/脚本、状态协议、会话设置处理及组合根：迁移授权页签、两个独立系统通知开关与全局保存/失败恢复。
- 本计划不承担测试开发；已完成测试断言与场景的历史证据按 `source_old_path=.ch/docs/exec-plans/completed/2026-11/2026-11-05-notification-tool-settings.md` 定位于[测试计划移除审计](../../migrations/test-plan-removals/2026-11-11-nov-active.json)。产品、排障与 ontology 文档由关联 docs 计划独立交付。
- 沿用既有主题、开关、应用级设置及通知宿主；不改权限、投递条件、默认值或窗口图标提醒。

## 验收标准

- 使用说明仅保留模式说明；工具设置新增“通知授权”，支持鼠标、键盘和窄面板。
- 两类系统通知开关读取当前配置，修改后全局持久化并立即生效；保存失败显示错误并恢复真实状态。
- 查询、刷新不申请权限；保留 Mac 未决定权限申请及拒绝后打开系统设置的行为。

## 影响面与风险

- 代码：Webview HTML、脚本、状态协议、会话设置处理及组合根。
- 风险：迁移后旧 DOM 引用残留、应用级配置误存工作区、窄面板标签溢出、失败后开关假成功。
- 缓解：复用两项 application 配置和现有提醒宿主；增加协议、保存失败、状态回显、页签与浏览器回归。

上述新增协议/回显/页签及浏览器断言属于已完成的历史测试开发，相关依据见上述来源审计；生产实现按相同契约验收。
