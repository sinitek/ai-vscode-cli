### 验收标准

- 超限且进入最旧窗口的 JSON 最终气泡可删除，不要求所有 JSON 立即消失。

- 文本最终答复、用户消息、活动输出保留；正文嵌入 JSON、非法 JSON 不误删。
- 宿主真正删除内存与临时存档，全新控制器重开不恢复。
