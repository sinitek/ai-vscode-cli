## 本类型历史记录

### 背景

Loop、Loop+ 派发子任务时往往只给粗粒度目标。子会话是新会话，看不到父规划推理，高难度设计关键点因此丢失。

### 目标

派发编码或其他执行任务时，把已确定的高难度设计关键点写进子任务能看到的说明。

### 范围

- Loop 主任务规划与派发提示。
- Loop+ 主任务决策提示和示例。

### 非目标

- 不新增用户必填表单，也不在缺少关键点时拒绝整份计划。
- 不改变子任务并发、冲突组和验收状态机。

### 验收标准

- [x] Loop / Loop+ 提示明确要求把设计关键点写进子任务 prompt，并给出示例。
- [x] 空白说明被丢弃，超长说明被截断，旧记录仍可读取。
- [x] 相关单测和 `npm run build` 通过。

### 影响面

- 代码目录：`src/extensionHost/`、`src/loopPromptBuilders.ts`、`src/webview/`

### 风险与缓解

- 风险：模型仍可能漏写关键点。
- 缓解：规则写进主提示和协议示例。

### 未决问题

- 无。
