# 龙虾群聊最终状态显示修复

- 日期：2026-06-18
- 状态：completed
- 负责人：Codex

## 背景

龙虾群聊任务结束后，群聊 UI 仍可能显示主任务处于执行中；同时成功完成或中断时，群聊对话缺少明确的最终状态气泡，用户无法判断任务是结束、中断还是仍在执行。

## 目标

修复龙虾群聊对话中的最终状态呈现：任务真正结束后不再显示主任务执行中，并且成功完成或中断时都在对话里显示明确的最终气泡。

## 范围

- 龙虾群聊任务状态判断与面板状态构建。
- 龙虾群聊 transcript/Markdown 渲染中的最终状态消息。
- 与上述逻辑直接相关的单元测试。

## 非目标

- 不改普通编辑任务行为。
- 不改龙虾子任务 tab 的执行状态展示规则。
- 不重构龙虾任务调度架构。

## 验收标准

- [x] 龙虾任务成功完成后，群聊对话里不再显示主任务执行中。
- [x] 龙虾任务中断、停止或进入人工复核后，群聊对话里不再显示主任务执行中。
- [x] 成功完成时，群聊对话最后有明确的成功完成气泡。
- [x] 中断、停止或人工复核时，群聊对话最后有明确的中断/停止气泡。
- [x] 普通编辑任务与龙虾子任务现有行为不变。

## 风险与缓解

- 风险：运行态判断过宽，导致真正运行中的龙虾任务不显示执行中。
- 缓解：运行态必须同时参考持久化任务状态和内存运行集合，结束态优先级高于内存残留。
