# 携宁 CLI 配置原生宽浮层

- 日期：2026-10-31
- 状态：completed
- 负责人：Codex

## 背景与目标

用户希望配置在 VS Code 自身“首选项—设置”同类的原生浮层中打开，而不是 AI 对话 Webview 内部弹层；尽量宽但不全屏。

## 范围与非目标

- 复用配置中心 HTML、消息协议、配置读写与档案定位。
- 优先使用本机 VS Code 已实现的模态编辑器；旧版本、用户禁用或命令失败时回退独立 VS Code 窗口，窗口命令失败时保留编辑器页。
- 原生浮层模式隐藏配置页自身的标题栏和右侧关闭按钮，填满内容高度；窄屏保留目录入口，回退模式保留原有标题。
- 移除配置页开关对编辑器组、主侧栏和辅助侧栏的全局布局切换。
- 不升级框架、依赖或最低 VS Code 版本，不修改用户的全局设置，不重做配置内容或工具设置。

## 验收标准

- 配置从原入口打开，原生工作台浮层不受聊天面板宽度限制。
- 默认非最大化，接近窗口宽度，支持 VS Code 原生关闭、拖动与缩放。
- 重复打开复用实例，保留最新档案导航和 UI 就绪握手。
- 不支持原生浮层时回退独立 VS Code 窗口，窗口命令失败仍保留配置页；打开/关闭均不切换侧栏、Zen Mode 或全屏。
- 相关回归单测、构建与本机最小验证通过；未验证的范围明确记录。

## 影响面

- `src/webview/configPanel.ts`、扩展注册生命周期、对应配置面板测试。
- 功能清单、配置中心规格、相关 ontology 与本计划。
- 无磁盘配置格式变化；不读取或写入用户私有配置作测试。

## 风险与缓解

- 原生模态编辑器尚无公开 WebviewPanel 显示参数：以已注册命令探测及异常回退隔离内部入口；保留独立窗口与普通编辑器降级路径。
- 并发打开和关闭：合并进行中的打开请求，以最新导航为准，按实例清理生命周期。
- VS Code 浮层尺寸由宿主管理：显式非最大化并使用宿主支持的尺寸参数，不注入工作台 DOM。
