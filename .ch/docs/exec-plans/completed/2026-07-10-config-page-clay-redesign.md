# 携宁 CLI 配置页 Clay 风格重构

## 目标

- 以用户提供的 Clay 设计规范为唯一视觉基准，重做“携宁 CLI 配置”页面。
- 覆盖主页面、左侧配置列表、编辑区、按钮、表单、卡片、消息、下拉、弹窗、确认框与抽屉。
- 保留现有业务行为、平台能力和 Monaco 编辑器语法高亮，仅调整视觉与必要的样式挂载点。

## 背景

- 当前页面被统一成纯白底、纯黑边框，层次过硬且缺少设计规范要求的暖色画布、柔和边界和卡片深度。

- 必要的执行计划与验证记录

## 非目标

- 不调整配置、MCP、Skills、导入导出等业务流程。
- 不改变后端协议、配置存储结构或国际化文案。
- 不替换前端框架或 Ant Design 版本。

## 设计约束

- 页面画布使用暖米色语义表面，卡片和浮层使用白色语义表面。
- 黑色作为主操作与选中态，暖灰作为次级文字和边界。
- 彩色仅用于状态、标签和轻量强调，不大面积抢占配置工作区。
- 使用 4 / 8 / 12 / 24px 圆角层级和 Clay 多层轻阴影。
- 选中配置行的操作图标为白色；激活按钮保持独立的 Lemon 黄底黑字状态，不随图标按钮变白。
- 动效克制：按钮轻微上移/旋转与硬阴影；尊重 reduced-motion。
- 颜色统一收敛到页面级语义变量和 Ant Design 主题 token，不在组件内散落新增颜色值。

## 验收标准

- 主页面、弹窗、抽屉、下拉、Popover、确认框视觉一致。
- Claude、Codex、OpenCode 三个平台配置视图保持可用且布局无溢出。
- 左侧选中行操作图标清晰，激活按钮与普通图标按钮可明确区分。
- 表单焦点、悬停、禁用、危险操作、成功/警告/错误状态均可辨识。
- 深色 VS Code 宿主主题下仍固定呈现设计规范的浅色页面。
- `node --check media/config/assets/config-app-ui.js` 通过。
- `npm run build` 通过。
- `git diff --check` 通过。

## 风险

- 配置前端当前直接维护构建资源，修改时必须避免覆盖工作区已有业务改动。
- Ant Design 浮层挂载在页面根节点之外，需要同时通过主题 token 和全局浮层选择器覆盖。
- 大量内联布局样式存在，优先用专属 class 和语义变量修正，避免无关重排。
